swaymp — Hackberry Pi Music Player

A complete stack turning a Hackberry Pi (CM5 handheld) into a dedicated music player: MPD + sway + PipeWire + Snapcast multiroom on a HyperPixel4 square panel.

GitHub repo Operator manual

What you get

  • PlaybackMPD user service, MPC keybinds: play/pause, next/previous, ±5s seek, volume + mute.
  • ClientsEuphonica on Now Playing, myMPD web UI, fuzzel launcher, F13 cheatsheet card.
  • MultiroomSnapcast Receiver / Broadcast / Group via Super+X, snapweb phone UI, mode restored at boot.
  • Handheld UIsway + waybar + Dracula theme on 720×720, bluetuith and wifitui TUIs.
  • Music deliverySyncthing folders for Sync, Music and Mixes.
